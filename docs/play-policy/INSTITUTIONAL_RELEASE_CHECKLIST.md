# Institutional release checklist

- Verify the production base URL and TLS configuration.
- Verify a dedicated reviewer/test account and test upload.
- Confirm authorization, privacy notice, and Data Safety declaration.
- Verify package/version/signing key and independent Companion regression build.
- Publish only the PGR Companion application from `android/app-companion`; do not create a second
  Android listing or hidden alternate track.
