# PGR Companion data deletion

PGR Companion does not create user accounts and does not transmit resident data to a server. All profile information, training records, reminders, and app-private document copies are stored locally on the user’s device.

To delete data, open **Profile → Delete All App Data** and confirm. This removes the local profile, all training records, reminders, preferences, and app-owned document copies. Individual records can also be deleted from their respective screens.

Because there is no account or cloud copy, there is no server-side account deletion request to process. Uninstalling the app also removes its app-private local data according to Android’s standard app-uninstall behavior.

PGR Companion is an independent productivity tool for postgraduate medical trainees and is not affiliated with any university, regulator, examination body, or government institution.
